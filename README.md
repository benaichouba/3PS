# English Adventure — Step 1 Final

This build uses the teacher-supplied artwork as the actual app screens.

## Included
- Supplied two-button start artwork (`buttons.jpg`): transparent click zones are placed over the existing **Sign Up** and **Exit** buttons. No duplicate button text is drawn.
- Supplied Sign Up artwork (`sign_up_page.jpg`): input fields are transparent overlays positioned over the four blank boxes; the fields were moved slightly to the right.
- Supplied educational main-page artwork (`main_page.png`) is displayed as the actual main screen after registration. Transparent hit areas sit over its three illustrated section arrows; no duplicate labels are drawn.
- App icon included.
- GitHub Actions workflow included at `.github/workflows/build.yml`.

The lesson content, payment/activation system, audio, and assessments are intentionally not added in this step.
